# Stagecraft Action Editor

Compose animation, VFX, audio, and gameplay signals on one timeline — then preview every action inside Unity without leaving the editor.

## Requirements

- **Unity 2022.3 LTS** (2022.3 or newer 2022.x)
- **Universal Render Pipeline (URP)** — Built-in and HDRP are not supported
